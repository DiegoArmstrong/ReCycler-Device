# ReCycler

## What is this project?
A battery cycler for testing and modelling second-life cells. 

## Why make this project?
I love batteries and want to know more about them! The end goal is to build a full testing and modelling suite (PCB + Firmware + Application) for second-life cells from scratch. 

## When do I find the time to work on this project?
When lectures get boring (most of the time)!
